平台概述

智枢 SITOP（Server Intelligent Task Orchestration Platform）是一款面向运维和系统管理员的服务器智能任务编排平台。它通过可视化的 Web 界面，让您能够高效地管理服务器资产、编排自动化初始化流程、集中管理脚本和软件包，并实时追踪批量任务的执行进度。

核心能力

  • 服务器资产管理 — 以分组形式组织服务器，支持多种认证方式（密码、密钥、跳板机），批量导入/导出、连通性检测
  • 脚本与模板编排 — 集中管理 Shell / Python 脚本，通过模板将脚本组合为多步骤自动化流水线
  • 软件仓库 — 基于 SFTP 的软件包管理，自动生成变量名并在脚本执行时注入下载链接
  • 任务执行引擎 — 四阶段执行流水线（连通性→健康检查→初始化→完成度检查），WebSocket 实时进度推送
  • 多租户隔离 — 数据完全隔离，支持独立的用户和权限管理
  • 审计与报告 — 完整的操作审计日志，支持 CSV / PDF 报告和 HTML 日志导出

角色与权限

SITOP 采用基于角色的访问控制（RBAC），共有三种角色：

🔑 管理员 (admin)

拥有全部权限，包括用户管理、审计日志查看、软件仓库删除操作

⚙️ 操作员 (operator)

可管理服务器、脚本、模板、执行任务、上传软件包，但不能管理用户或查看审计日志

👁 只读 (viewer)

仅可查看仪表盘、服务器、脚本、模板、任务和仓库信息，不能执行任何写操作

服务器管理

服务器管理模块是 SITOP 的核心功能之一，采用左分组、右列表的双面板布局，支持服务器分组管理和批量操作。

服务器分组

左侧面板展示所有服务器分组，每个分组右侧显示该组服务器数量的角标。

新建分组

  1. 点击左上角新建分组按钮
  2. 填写分组名称（必填）、描述（选填）
  3. 可选择默认凭据：该分组内服务器若未单独指定凭据，将使用此默认凭据
  4. 开启/关闭自动巡检：启用后系统会定期对分组内服务器进行连通性检测
  5. 点击创建完成

分组操作

点击分组右侧的 ⋯ 图标，可执行：

  • 分组详情 — 查看分组描述、默认凭据、自动巡检状态及成员服务器列表
  • 编辑分组 — 修改分组名称、描述、默认凭据和巡检设置
  • 删除分组 — 删除分组后，组内服务器将自动归入"未分组"

服务器列表

右侧面板展示选中分组下的所有服务器，支持多维度筛选和排序。

添加服务器

  1. 点击右上角添加服务器按钮
  2. 填写主机名（必填）、IP 地址（必填）、端口（默认 22）
  3. 选择协议（SSH / RDP / Telnet / VNC）和平台（Linux / Windows / Unix / 网络设备 / 其他）
  4. 设置连接超时和执行超时时间
  5. 选择认证方式（详见下方 SSH 凭据管理）
  6. 选择所属分组和标签
  7. 点击添加完成

搜索与筛选

  • 搜索框：支持按主机名、IP 地址、标签搜索，可切换模糊/精确模式
  • 列筛选：点击表头筛选图标，可按端口、协议、平台、连通性状态、分组、标签过滤
  • 分页：支持 20/50/100/200 条每页或查看全部

服务器详情

点击任意服务器行，右侧将滑出详情抽屉，展示完整信息包括：主机名、IP、端口、协议、平台、系统信息、连通性状态、最后检测时间、超时设置、SSH 凭据、所属分组、标签和备注。

批量操作

勾选多台服务器后，点击右上角批量操作按钮：

  • 批量连通性测试 — 对所有选中服务器进行 SSH 连通性检测
  • 批量更新凭据 — 将选中服务器的 SSH 凭据统一更新为指定凭据
  • 移动分组 — 将选中服务器移动到新的分组（替换现有分组）
  • 增加分组 — 为选中服务器追加新的分组（保留现有分组）
  • 批量删除 — 删除所有选中的服务器

导入与导出

  • 导入：支持通过 CSV 文件批量导入服务器（详见 CSV 导入格式），可下载 CSV 模板
  • 导出：将当前分组的服务器列表导出为 CSV 文件

连通性测试与命令执行

  • 测试连通性：对当前分组所有服务器进行 SSH 连接测试
  • 执行命令：在当前分组的所有服务器上执行指定命令，实时展示各服务器的执行结果

SSH 凭据管理

SSH 凭据用于连接目标服务器执行远程命令。凭据可预先创建并复用，也可在添加服务器时即时创建。

认证方式

认证类型说明所需信息
密码使用用户名 + 密码登录用户名、密码
SSH 密钥使用 SSH 私钥认证用户名、私钥内容
SSH 密钥 + 密码加密私钥 + 解密密码用户名、私钥内容、私钥密码
临时 Token一次性临时令牌用户名、Token 内容

跳板机配置

凭据支持配置跳板机（Jump Host），用于需要通过堡垒机访问内网服务器的场景：

  • 跳板机地址：堡垒机的 IP 或域名
  • 端口：跳板机 SSH 端口（默认 22）
  • 跳板用户：登录跳板机的用户名
跳板机使用与凭据相同的认证信息（密码或密钥）进行连接。

凭据优先级

服务器连接时的凭据选择优先级：

  1. 服务器自身指定的 SSH 凭据
  2. 所在分组的默认凭据
  3. 若均未配置，连接将失败

脚本库

脚本库集中管理用于服务器初始化的 Shell 和 Python 脚本。每个脚本都有明确的类型分类，支持版本管理和在线测试运行。

脚本类型

类型用途执行阶段
健康检查在初始化前检测服务器环境是否满足前置条件第 2 阶段
初始化步骤执行具体的初始化操作（安装软件、配置服务等）第 3 阶段
完成度检查验证初始化是否成功完成第 4 阶段

新建脚本

  1. 点击右上角新建脚本按钮
  2. 填写脚本名称（必填）
  3. 选择脚本类型（健康检查 / 初始化步骤 / 完成度检查）
  4. 选择语言（Shell / Python）
  5. 填写描述信息
  6. 在代码编辑器中编写脚本内容
  7. 点击保存

插入软件包变量

在脚本编辑器中，点击插入软件包变量按钮，将弹出软件仓库文件选择器：

  1. 浏览仓库目录，找到需要的软件包文件
  2. 点击文件右侧的插入按钮
  3. 系统将在光标位置自动插入 curl -fsSL -O "$PKG_XXX" 下载命令
  4. 变量名由系统自动生成（规则：PKG_ + 文件名大写 + 非字母数字转下划线）
脚本执行时，SITOP 会自动注入所有软件包变量（export），脚本中可直接使用 $PKG_XXX 变量获取对应的 HTTP 下载链接。

测试运行

点击脚本操作栏的测试运行按钮：

  1. 选择一个服务器分组
  2. 选择该分组下的一台服务器
  3. 点击执行，系统将把脚本发送到目标服务器执行
  4. 执行完成后展示退出码和输出内容
测试运行会在目标服务器上实际执行脚本内容，请确保脚本安全无害。

模板管理

模板将多个脚本按照特定顺序编排为一个可复用的初始化方案。创建任务时，只需选择模板和服务器分组即可执行。

模板结构

一个完整的模板包含以下部分：

  • 健康检查脚本（可选）— 在初始化前验证服务器环境
  • 初始化步骤（1~N 个）— 按顺序执行的脚本步骤
  • 完成度检查脚本（可选）— 在初始化后验证执行结果

创建模板

  1. 点击新建模板按钮
  2. 填写模板名称和描述
  3. 选择健康检查脚本（可选）
  4. 选择完成度检查脚本（可选）
  5. 添加初始化步骤：
    • 每个步骤选择一个初始化步骤类型的脚本
    • 设置超时时间（10~3600 秒）
    • 设置失败策略：中断（abort）/ 继续（continue）/ 重试（retry）
  6. 可点击+ 添加步骤增加更多步骤，或点击 🗑️ 删除步骤
  7. 点击保存

软件仓库

软件仓库提供基于 SFTP 的文件管理功能，用于存储初始化过程中需要的软件安装包、配置文件等资源。

文件浏览

仓库以目录树形式展示文件，顶部面包屑导航可快速跳转目录层级。每个文件自动生成一个变量名，格式为 PKG_ + 文件名大写（非字母数字字符转为下划线）。例如：

  • mysql-8.0.26.tar.gz → PKG_MYSQL_8_0_26_TAR_GZ
  • nginx.conf → PKG_NGINX_CONF

文件操作

  • 上传文件（操作员/管理员）：点击上传文件按钮，支持拖拽上传，同名文件自动重命名为 name(1).ext，单文件最大 1GB
  • 下载文件：优先通过 HTTP 直链下载，不可达时回退到后端代理下载
  • 复制变量：点击复制变量将变量名复制到剪贴板
  • 删除文件（仅管理员）：需二次确认，操作不可恢复
  • 批量删除（仅管理员）：勾选多个文件后批量删除
  • 搜索：按文件名在当前目录内搜索
  • 排序：支持按名称、大小、修改时间排序

变量注入机制

当任务执行脚本时，SITOP 会自动将仓库中所有文件的变量以 export 形式注入，变量值为该文件的 HTTP 下载地址。脚本中可直接使用：

curl -fsSL -O "$PKG_MYSQL_8_0_26_TAR_GZ"
在脚本库编辑器中可使用"插入软件包变量"按钮一键插入下载命令，无需手动复制变量名。

任务中心

任务中心是 SITOP 的核心执行模块，负责将模板中定义的初始化方案批量应用到目标服务器分组。

创建任务

  1. 点击新建任务按钮
  2. 选择一个初始化模板
  3. 选择一个服务器分组
  4. 点击启动任务

任务创建后，系统将自动开始对分组内所有服务器执行初始化流程。

四阶段执行流水线

1. 连通性检查
→
2. 健康检查
→
3. 初始化执行
→
4. 完成度检查

任务详情

点击任务的详情按钮，打开详情对话框：

  • 步骤条：顶部展示四阶段进度
  • 基本信息：状态、当前阶段、完成进度
  • 完成度矩阵：表格形式展示每台服务器在各阶段的通过/失败状态
  • 服务器任务列表：展示每台服务器的执行日志摘要

实时进度

对于运行中的任务，系统通过 WebSocket 实时推送进度更新，同时以 2 秒间隔轮询作为后备。无需手动刷新即可看到最新状态。

导出功能

  • 导出全部日志：生成自包含的 HTML 文件，包含完整的执行记录、命令输出和统计数据，支持按状态筛选和主机名搜索
  • 导出 CSV：将任务结果导出为 CSV 格式报告
  • 导出 PDF：将任务结果导出为 PDF 格式报告

取消任务

对于等待中或运行中的任务，可点击取消任务按钮。正在执行的步骤会在当前阶段结束后停止。

常见问题

Q: 服务器连通性检测失败怎么办？

请检查以下几点：

  1. 目标服务器的 IP 地址和 SSH 端口是否正确
  2. SSH 凭据是否配置正确（密码/密钥是否有效）
  3. 网络是否可达（防火墙规则、安全组设置）
  4. 如果使用跳板机，确认跳板机地址和凭据正确

Q: 任务执行过程中某步骤失败了怎么办？

在任务详情中查看该服务器对应步骤的执行日志，分析错误输出。根据模板中设置的失败策略：

  • 中断：该服务器跳过后续步骤，标记为失败
  • 继续：跳过失败步骤，继续执行后续步骤
  • 重试：自动重试该步骤（最多 3 次）

Q: 如何在脚本中使用软件仓库的文件？

在脚本编辑器中使用"插入软件包变量"按钮，或手动编写：

curl -fsSL -O "$PKG_文件名大写"

变量名自动生成规则：PKG_ + 文件名转大写 + 非字母数字字符转下划线。

Q: 导出的 CSV 文件乱码？

CSV 使用 UTF-8 编码。在 Excel 中打开时，请使用"数据 → 从文本/CSV"导入功能，手动选择 UTF-8 编码。

CSV 导入格式

服务器管理模块支持通过 CSV 文件批量导入服务器。可在导入对话框中下载 CSV 模板。

字段说明

字段必填说明
hostname✅主机名（支持中文）
ip✅IP 地址，全局唯一，重复会报错
auth_type❌认证方式：password / credential；留空但填写了用户名+密码时自动按密码认证
auth_username❌认证用户名（密码认证时必填）
auth_password❌认证密码（密码认证时必填，入库加密存储）
labels❌标签，逗号分隔可填多个，如：生产,高优
tags❌附加标签，逗号分隔可填多个，如：nginx,db
groups❌分组名，逗号分隔；不存在时自动创建，如：web,db
ssh_port❌SSH 端口，默认 22
protocol❌连接协议，默认 ssh
platform❌系统平台，默认 linux
comment❌备注（支持中文）

示例 CSV

hostname,ip,auth_type,auth_username,auth_password,labels,tags,groups,ssh_port,protocol,platform,comment
